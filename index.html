Kenapa Enrai

Dibuat untuk yang sedang membangun.

Lapisan tipis di depan beberapa provider model. Anda tetap memakai SDK, prompt, dan kode yang sudah ada — Enrai yang mengurus perutean.

⌁

Endpoint kompatibel OpenAI

POST /v1/chat/completions dan GET /v1/models mengikuti bentuk OpenAI, jadi SDK dan tools yang sudah ada bekerja hanya dengan mengganti base URL.

⇉

Failover provider otomatis

Setiap nama model adalah combo yang dikelola server. Bila satu provider gagal, permintaan dialihkan ke anggota combo lain alih-alih mengembalikan jawaban kosong.

≡

Streaming SSE

Kirim "stream": true dan baca potongan jawaban secara real-time dalam format chunk OpenAI, diakhiri [DONE].

◎

Satu key, banyak model

Tanpa akun per provider. Satu key dari dashboard membuka semua model yang tersedia, dan /v1/models menunjukkan apa yang aktif saat ini.

⏱

Limit yang dipublikasikan

20 request chat per menit (burst 5) dan 60 request daftar model per menit, per key. Angkanya tertulis di depan, bukan muncul sebagai 429 misterius.

⌘

Masuk ke stack Anda

curl, Node.js, Python, PHP, atau klien apa pun yang bicara format OpenAI — termasuk editor dan tools yang mengizinkan base URL kustom.

FAQ

Pertanyaan yang benar-benar ditanyakan.

Apakah benar-benar gratis?

Ya. Selama public beta tersedia tier gratis tanpa kartu kredit: satu key, semua model yang tersedia, dengan limit yang dipublikasikan di halaman harga.

Apakah aplikasi saya harus ditulis ulang?

Tidak. Kalau Anda sudah memakai SDK OpenAI atau klien kompatibel OpenAI, cukup ganti base URL menjadi https://enrai.web.id/v1 dan API key. Bentuk request, payload, dan response tetap sama.

Apa yang terjadi kalau provider sedang down?

Setiap nama model adalah combo beberapa provider. Permintaan yang gagal diulang ke anggota combo lain. Bila semua percobaan kosong, Anda menerima 502 dengan pesan error, bukan jawaban kosong.

Apakah streaming didukung?

Ya — "stream": true mengembalikan Server-Sent Events dalam format chunk OpenAI, diakhiri [DONE].

Bagaimana dengan data saya?

Prompt diteruskan ke provider upstream yang melayani request tersebut; lihat kebijakan privasi dan ketentuan layanan. Jangan kirim rahasia yang tidak akan Anda kirim ke API pihak ketiga.

Apakah siap untuk produksi?

Statusnya public beta. Cocok untuk prototipe, proyek sampingan, dan tools internal — siapkan provider kedua untuk apa pun yang tidak boleh gagal.

Ambil key, kirim satu request.

Gratis selama public beta. Kalau request pertama mengembalikan teks, bagian tersulit sudah lewat.
