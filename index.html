Why Enrai

Built for people who ship prototypes.

A thin, compatible layer in front of several model providers. You keep your SDK, your prompts and your code — Enrai handles the routing.

⌁

OpenAI-compatible endpoints

POST /v1/chat/completions and GET /v1/models follow the OpenAI shape, so existing SDKs and tools work by changing the base URL.

⇉

Automatic provider failover

Each model name is a combo managed server-side. If one upstream provider fails, the request moves to another member of the combo instead of returning an empty answer.

≡

Streaming that behaves

Send "stream": true and read Server-Sent Events. A heartbeat keeps long generations from going silent behind proxies.

◎

One key, many models

No per-provider accounts. One key from the dashboard unlocks every available model, and /v1/models lists what is live right now.

⏱

Honest, published limits

20 chat requests per minute (burst 5) and 60 model-list requests per minute, per key. The limits are documented up front instead of appearing as mystery 429s.

⌘

Works with your stack

curl, Node, Python, PHP, or any client that speaks the OpenAI format — including editors and agent tools that let you set a custom API base.

FAQ

Questions people actually ask.

Is it really free?

Yes. During public beta the API has a free tier with no credit card: one key, every available model, the published rate limits. Paid plans are managed from the admin panel when you need more.

Do I have to rewrite my app?

No. If you already use the OpenAI SDK or an OpenAI-compatible client, change the base URL to https://enrai.web.id/v1 and the key. Requests, payloads and response shapes stay the same.

What happens when a provider goes down?

Each model name is a combo of upstream providers. A request that fails is retried against another member of the combo. If every attempt comes back empty, you get a 502 with an error message instead of a blank answer.

Do you support streaming?

Yes — "stream": true returns Server-Sent Events in the standard OpenAI chunk format, terminated with [DONE].

What about my data?

Prompts are forwarded to the upstream provider that serves the request; see the privacy policy and terms for details. Do not send secrets you would not send to a third-party API.

Is it production-ready?

It is a public beta. Use it for prototypes, side projects, internal tools and evaluation — and keep a second provider configured for anything that must never fail.
