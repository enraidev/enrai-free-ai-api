# Changelog

All notable changes to this repository are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.1.0] - 2026-11-18

### Changed

- **English is now the primary documentation language.** `README.md`, `docs/*.md`, `llms.txt`,
  `index.html`, the community files and the GitHub templates are written in English for search
  engines and AI assistants.
- **Indonesian is the secondary language.** The full Indonesian README is `README.id.md`; the
  technical docs are translated under `docs/id/`, and `index.id.html` is the Indonesian landing page
  with `hreflang` links to the English one.
- README restructured for search and answer engines: keyword-bearing H1, table of contents,
  features, model and rate-limit tables, quick start, copy-paste examples, error table, use cases
  and FAQ.
- Example scripts, `.env.example` and the banner/social assets use English copy.
- Repository description and topics reviewed for English-language discovery.

### Added

- `README.id.md` and `docs/id/{getting-started,api-reference,models,faq}.md`.
- `index.id.html` with `hreflang` alternates (`en`, `id`, `x-default`).

## [1.0.0] - 2026-11-17

### Added

- README with banner, architecture diagram, model table, rate-limit table, cURL/Python/Node.js
  examples and FAQ.
- `docs/getting-started.md`, `docs/api-reference.md`, `docs/models.md`, `docs/faq.md`.
- Runnable examples: `examples/python` (OpenAI SDK), `examples/nodejs` (dependency-free `fetch`),
  `examples/curl`.
- `examples/openai-sdk` for Python and Node.js using the official `openai` package.
- Community files: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, issue and pull request
  templates, `CODEOWNERS`.
- CI workflow (markdownlint, link check, example syntax checks, local-URL guard) and Dependabot
  configuration.
- Brand assets: `assets/banner.svg` and `assets/social-preview.png` (generated by
  `scripts/generate_assets.py`).
- `index.html` with SEO metadata, JSON-LD, `sitemap.xml` and `llms.txt`.

### Changed

- Repository renamed from `enrai-promo` to `enrai-free-ai-api`; the old address redirects to the new
  one.
- The previous README was replaced by full documentation; local URL references were removed.
- Licence split: MIT for example code, CC BY 4.0 for documentation.
